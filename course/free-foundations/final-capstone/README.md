# Northbridge Final Capstone — Content Manifest

**Brand:** Ninomae OSINT

**Course:** Free Foundations V1.0

**Status:** Original approved Northbridge Expansion Claim retained as the **only required final capstone**.

## Approved assessment design
- Entirely fictional case with twelve numbered evidence records (E001–E012).
- 45-minute assessment in five stages.
- 15 multiple-choice questions; Q01–Q10 worth 6 points each; Q11–Q15 worth 8 points each.
- Total 100 points, passing threshold 80.
- Student written findings worksheet for separate qualitative review; no currently approved automatic points for the written exercise.

## Public material
- `student-capstone.md`: original learner-facing case and evidence packet; approved question wording and response choices; blank written report worksheet.

## Excluded from public GitHub
- Correct options, assessment explanations and instructor grading rubric.
- Filled example/model findings report that could reveal correct answers.

## Boundaries
The capstone is **content only**: it is not an operating assessment interface, authenticated submission form or certificate-issuing process. Separate backend integration and controlled answer-key provisioning remain outstanding.

No real Blackbird investigation is mandatory in Foundations; JP-01, JP-02 and JP-04 are not substituted for this capstone. No website markup, styling, assets or Brevo integration modified by this content commit.
